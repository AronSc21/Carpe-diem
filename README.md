# Carpe Diem (prototipo)
Abre la carpeta en VS Code y haz doble clic en `index.html` o usa Live Server.
- `data/config.js`: teléfono, WhatsApp, horario, redes y `MOSTRAR_POR_CONFIRMAR` (false oculta todas las marcas).
- `data/promociones.js`, `precios.js`, `instrumentos.js`, `calendario.js`: edítalos sin tocar el código.
- Logo: reemplaza `assets/logo.svg` (mismo nombre).
- Buscar pendientes: busca "Por confirmar" o `null` en `data/`.
- Colores: variables al inicio de `css/estilos.css`.
Prototipo privado: no publicar sin autorización de la academia.
